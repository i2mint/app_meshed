# app_meshed

app_meshed: HTTP services and frontend for meshed operations.

This package provides a modular, source-keyed architecture for:

- DAG construction and execution (meshed)
- Data storage and access (dol)
- Stream visualization (creek, slabs)
- Function introspection and form generation (i2, ju)
- HTTP service layer (qh, fastapi)
