# app_meshed.cli

CLI for running the app_meshed server.

This module provides a command-line interface for starting the
app_meshed HTTP server.

| [`main`](#app_meshed.cli.main)()                 | Main CLI entry point.         |
|-------------------------------------------------------------------------|-------------------------------|
| [`setup_logging`](#app_meshed.cli.setup_logging)([level]) | Set up logging configuration. |
